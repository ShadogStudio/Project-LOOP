# Project LOOP — 기획 문서

## 개요

- **프로젝트**: Project LOOP
- **목적**: 포트폴리오용 Unity 프로젝트 (공개 Git 베이스 + 로컬 풀에셋 빌드)
- **장르**: 3D 탑다운 로그라이크
- **엔진**: Unity 6 (URP)

## 핵심 판타지

마을을 거점으로 던전에 반복 진입한다. 성공적으로 복귀하면 수확물을 마을에 쌓고, 죽으면 이번 런에서 챙긴 것은 잃는다.

## 핵심 루프

```text
마을 (준비 / 영구 재화 소비)
  → 던전 입장
  → 탐험 / 런 전리품 수집
  → 마을 복귀 (전리품 예치)  또는  사망 (런 전리품 손실)
  → 반복
```

## 경제 규칙

| 위치 | 재화 | 사망 시 | 성공 복귀 시 |
|------|------|---------|--------------|
| 마을 지갑 | 영구 골드 | 유지 | 런 전리품을 예치받아 증가 |
| 런 인벤토리 | 던전에서 휴대하는 전리품 | 초기화 | 마을 지갑으로 예치 |

## 아키텍처 (확정)

### 핵심 시스템 — 자체 구현

이동, 카메라, 전투, 재화, 런 루프는 **자체 구현**한다. 완성형 템플릿에 핵심 로직을 맡기지 않는다. 공개 Git에는 자체 코드·플레이스홀더로 실행 가능한 베이스를 둔다.

### 던전 생성 — 교체 가능한 제공자

```text
게임 코드
  → IDungeonGenerator
       ├─ SimpleProceduralDungeonGenerator   ← 현재 사용
       └─ (예약) 전용 던전 도구 어댑터
```

게임플레이는 생성기 구현체가 아니라 **레이아웃·스폰·출구 결과**만 본다. 외부 도구가 없어도 컴파일·실행된다.

### 에셋·온라인 훅

| 훅 | 목적 | 현재 |
|----|------|------|
| `IDungeonGenerator` | 던전 레이아웃 | Simple 구현 사용 중 |
| 외형(캐릭터·환경) | 플레이어·적·모듈 | 플레이스홀더 (로컬 ThirdParty 연결 예정) |
| `ISaveService` | 메타 저장 | PlayerPrefs 로컬 구현 |
| `IOnlineServices` | 클라우드 저장·업적 | Null 스텁 (EOS는 v2+) |

로컬 전용 에셋: `Assets/ThirdParty/` (Git 미포함, README만). 시각 톤은 판타지 로우폴리. 구체 팩 목록은 문서에 두지 않는다.

### 온라인 (v2+)

EOS는 클라우드 저장·업적만 대상. 게임 코드는 `IOnlineServices`만 호출. 자격 증명은 공개 Git에 올리지 않는다. 멀티플레이는 범위 밖.

## 확정 게임플레이 (v1)

| 항목 | 결정 |
